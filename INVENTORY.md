# INVENTORY — реестр компонентов

Читается перед любой вёрсткой. Прежде чем создавать компонент, проверь, что его здесь нет.

Секция **«Не использовать для»** обязательна у каждой записи. Именно она предотвращает появление пятого варианта карточки.

Статус: `готов` — можно использовать. `нужен` — в аудите найден, ещё не построен.

Любое изменение компонента фиксируется в `src/docs/Changelog.mdx` — в том же
коммите и с причиной, а не только с фактом.

Каждая запись обязана иметь story-файл, и наоборот. Поля `Варианты` и `Состояния`
задают обязательный набор историй: `Variants`, `States`. Расхождение ловит
`npm run ds:stories` — это блокер, а не задача «когда-нибудь».

## Примитивы

### Stack
- **Слой:** primitive
- **Пропы:** `direction` (row|column), `gap` (SpaceToken), `align`, `justify`, `wrap`, `grow`, `as`
- **Варианты:** —
- **Состояния:** —
- **Используется:** везде
- **Не использовать для:** сеток из трёх и более колонок — для них нужен `Grid`. Не использовать вместо `Box`, когда нужен только внутренний отступ.
- **Статус:** готов

### Box
- **Слой:** primitive
- **Пропы:** `padding`, `paddingX`, `paddingY` (SpaceToken), `background` (SurfaceColorToken), `radius`, `border`, `fullWidth`, `as`
- **Варианты:** —
- **Состояния:** —
- **Используется:** везде
- **Не использовать для:** расстояния между соседями — это задача `Stack gap`. Box намеренно не умеет внешние отступы.
- **Статус:** готов

### Text
- **Слой:** primitive
- **Пропы:** `variant` (TextVariantToken), `color` (TextColorToken), `truncate`, `align`, `as`, `htmlFor`, `id`
- **Варианты:** caption, bodySm, body, bodyLg, label, headingSm, headingMd, headingLg
- **Состояния:** —
- **Используется:** везде
- **Не использовать для:** подгонки размера под макет. Роль выбирается по смыслу; если смысл требует другого размера — это вопрос к шкале, а не к месту применения.
- **Статус:** готов

### Surface
- **Слой:** primitive
- **Пропы:** `level` (ElevationToken), `border`, `radius`, `padding`, `background`, `interactive`, `fullWidth`, `as`
- **Варианты:** flat, raised, overlay, modal
- **Состояния:** hover, active, focus-visible — только при `interactive`
- **Используется:** EmptyState, Drawer, панели
- **Не использовать для:** модалок — у `Modal` своя поверхность с оговорённым исключением из правила «тень или бордер».
- **Статус:** готов

### Field
- **Слой:** primitive
- **Пропы:** `label`, `children` (render-функция), `variant`, `hint`, `error`, `required`, `fullWidth`
- **Варианты:** `stacked` (подпись над контролом, по умолчанию), `floating` (подпись в поле, уходит наверх при вводе)
- **Состояния:** default, focus, filled, error, disabled
- **Используется:** все формы
- **Не использовать для:** полей без подписи. Поле без подписи — это поле без назначения; если подпись мешает макету, это вопрос к макету. Не делать отдельный компонент для плавающей подписи — это вариант, иначе появятся два способа подписать поле и они разойдутся.
- **Примечание:** `floating` держится на `:placeholder-shown`, поэтому контрол обязан прокинуть `placeholder` из render-пропов. Контролы с собственным триггером (`Select`) сообщают заполненность через `data-filled`. Условия подъёма проверяются через `:has()` на боксе поля, а не соседним селектором: триггер `Select` лежит внутри обёртки `Popover`, и до него соседний селектор не доставал.
- **Статус:** готов

### Grid
- **Слой:** primitive
- **Пропы:** `columns` (2|3|4), `gap` (SpaceToken), `rowGap`, `as`
- **Варианты:** 2, 3, 4 колонки
- **Состояния:** —
- **Используется:** раскладка форм, сетки карточек
- **Не использовать для:** двух элементов рядом — это `Stack direction="row"`. Не использовать как таблицу: сетка не связывает ячейки в строки и не сортируется.
- **Примечание:** схлопывания в одну колонку нет — для этого нужна шкала брейкпоинтов, которой в системе пока не существует. Заводить её ради одного компонента — значит выдумать шкалу на глаз.
- **Статус:** готов

### Icon
- **Слой:** primitive
- **Пропы:** `name` (IconName), `size` (sm|md|lg), `color` (TextColorToken), `label`
- **Варианты:** 33 иконки Lucide, обводка 1.5 — 32 прикладных и служебная `placeholder`
- **Состояния:** наследует `currentColor` от родителя
- **Используется:** Button, Tag, Modal, EmptyState, Badge, Table, Stepper, SegmentedControl, Link
- **Не использовать для:** иллюстраций и схем. Набор закрыт: добавление иконки требует согласия, как и добавление токена.
- **Примечание:** `placeholder` — только для витрины. Стоит в демонстрационных блоках, где иконка показывает форму компонента, а не конкретное действие; в приложении её быть не должно. Конкретные иконки живут в блоке `Usage`.
- **Статус:** готов

## Компоненты

### Button
- **Слой:** component
- **Собран из:** Icon
- **Пропы:** `variant`, `size`, `iconStart`, `iconEnd`, `fullWidth`, `loading`, + нативные пропы `<button>`
- **Пропы квадратной формы:** `icon` + обязательный `aria-label` вместо `children`. `iconStart`, `iconEnd` и `fullWidth` при этом запрещены типами
- **Варианты:** primary, secondary, ghost, danger — каждый в двух формах: с текстом и только с иконкой (квадрат, ширина равна высоте контрола)
- **Состояния:** default, hover, active, focus-visible, disabled, loading
- **Используется:** везде
- **Не использовать для:** навигации по ссылке — нужен `Link`. Не ставить две `primary` на один экран: если их две, главное действие не выбрано. Не собирать квадратную кнопку вручную из `ghost` + `Icon` — форма приедет на глаз, как в аудите (три разных написания одного и того же).
- **Статус:** готов

### Modal
- **Слой:** component
- **Собран из:** Text, Icon
- **Пропы:** `open`, `onClose`, `title`, `children`, `footer`, `size` (sm|lg), `dismissible`
- **Слоты:** шапка (заголовок + закрытие) — зашита; содержимое — свободно; футер — `Modal.Footer` с пропом `aside`
- **Состояния:** открыта, закрыта; удержание фокуса, возврат фокуса, блокировка прокрутки страницы, закрытие по Esc и клику по фону. Открытие и закрытие анимированы: окно остаётся в дереве, пока доигрывает уход
- **Используется:** подтверждения, формы, визарды
- **Не использовать для:** выпадающих меню и поповеров — нужен `Popover`. Не зашивать внутрь частные решения: всё содержимое приходит снаружи.
- **Статус:** готов

### Input
- **Слой:** component
- **Пропы:** `size`, `invalid`, `fullWidth`, + нативные пропы `<input>`
- **Варианты:** два типа поля — `stacked` (подпись над полем) и `floating` (подпись уходит наверх при вводе). Тип задаётся пропом `variant` у `Field`: различаются они именно подписью, сам контрол один и тот же
- **Состояния:** default, hover, focus, focus-visible, invalid, disabled
- **Используется:** формы, фильтры, поиск
- **Не использовать для:** многострочного ввода — нужен `Textarea`. Не применять плавающую подпись: подпись ставит `Field`, одинаково для всех полей.
- **Статус:** готов

### Tag
- **Слой:** component
- **Собран из:** Icon
- **Пропы:** `color` (TagColorToken), `onRemove`
- **Варианты:** steel, sage, amber, clay, violet, slate
- **Состояния:** default; hover и focus-visible у кнопки снятия
- **Используется:** метки проектов, фильтры
- **Не использовать для:** статусов системы (успех, ошибка, предупреждение) — там цвет означает роль, а здесь пользовательский выбор. Для статусов нужен `Badge`.
- **Статус:** готов

### EmptyState
- **Слой:** component
- **Собран из:** Stack, Text, Icon
- **Пропы:** `title`, `description`, `icon`, `action`
- **Варианты:** —
- **Состояния:** —
- **Используется:** любые области с данными, Table
- **Не использовать для:** состояния загрузки — нужен `Skeleton`. Не использовать для ошибок сети: формулировка идёт от состояния данных, а не от сбоя системы.
- **Статус:** готов

### Cell
- **Слой:** component
- **Собран из:** Text
- **Пропы:** `children`, `description`, `leading`, `trailing`, `size`, `tone`, `selected`, `disabled`, `onClick`, `role`
- **Варианты:** статичная и интерактивная; тон `default | danger`
- **Состояния:** default, hover, focus-visible, active, selected, disabled
- **Используется:** варианты `Select`, меню и списки внутри `Popover`, сводка выбранного
- **Не использовать для:** произвольной вёрстки внутри строки — слотов ровно два, и третьего не будет. Если полей три и их сравнивают между строками сверху вниз, это `Table`. Не использовать как кнопку в форме — там `Button`: у ячейки нет ни рамки, ни веса действия. Не использовать `tone="danger"` для «просто важного» пункта — красный означает потерю данных.
- **Примечание:** раскладка не настраивается — в этом весь смысл компонента. Левый слот фиксирован по ширине (`space.lg`, у `lg` — `space.xl`), поэтому подписи соседних строк стоят в одном столбце; строке без иконки в таком списке передаётся `leading={null}` — явный пустой слот. Строка занимает всю ширину списка: иначе фон наведения обрывается по буквам, а подписи встают по центру панели. Без `role` интерактивная строка рисуется `<button>` и берёт клавиатуру от платформы; с ролью (`option`, `menuitem`) Enter и пробел обрабатывает сама ячейка.
- **Статус:** готов

### Popover
- **Слой:** component
- **Пропы:** `open`, `onClose`, `trigger`, `children`, `placement`, `width`, `title`, `footer`, `fullWidth`
- **Варианты:** размещение `bottom-start | bottom-end | top-start | top-end`; ширина `auto | trigger | sm | md`
- **Примечание:** `placement` — предпочтение. Размещение считает floating-ui: `flip` (переворот), `shift` (сдвиг от кромки), `size` (подрезка высоты по свободному месту), `autoUpdate` (пересчёт на прокрутке предков, ресайзе и изменении размеров). Панель рисуется в портале и позиционируется от вьюпорта — контейнер с прокруткой её не режет. Фокус через портал ведёт `FloatingFocusManager`, закрытие — `useDismiss`
- **Состояния:** открыт, закрыт; закрытие по Esc и клику снаружи, возврат фокуса на триггер. Открытие и закрытие анимированы; на время ухода панель не ловит указатель
- **Используется:** панель фильтров, выбор режима, действия над диаграммой, внутренности `Select`. Строки внутри панели — `Cell`, а не собственная вёрстка вызывающего
- **Не использовать для:** решений, где ответ обязателен — поповер не блокирует интерфейс и закрывается случайным кликом; для этого есть `Modal`. Не использовать для подсказок по наведению — нужен `Tooltip`.
- **Статус:** готов

### Drawer
- **Слой:** component
- **Пропы:** `open`, `onClose`, `children`, `footer`, `title`, `size`
- **Варианты:** `wide` (min(920px, 64%)), `narrow` (min(420px, 80%))
- **Состояния:** открыта, закрыта; закрытие по Esc и клику по затемнению. Открытие и закрытие анимированы: панель уезжает туда же, откуда приехала
- **Используется:** панель результата расчёта («Смотреть результат»), список пользователей
- **Не использовать для:** содержимого, требующего блокировки всего интерфейса — панель намеренно оставляет шапку доступной; для этого есть `Modal`.
- **Требование:** родитель обязан иметь `position: relative` и `overflow: hidden` — панель позиционируется абсолютно внутри рабочей области.
- **Статус:** готов

### Select
- **Слой:** component
- **Собран из:** Popover, Cell, Checkbox, Icon
- **Пропы:** `options`, `value`, `onChange`, `placeholder`, `size`, `multiple`, `clearable`, `searchable`, `allowCustom`, `footer`, `disabled`, `invalid`, `fullWidth`
- **Варианты:** одиночный и множественный выбор; с поиском; со свободным вводом; с группами; с футером; со снятием выбора и без (`clearable`)
- **Состояния:** default, hover, open, focus-visible, invalid, disabled, пустой результат поиска
- **Используется:** фильтры, формы, выбор заказчика
- **Не использовать для:** выбора из двух-трёх взаимоисключающих вариантов, которые помещаются на экран — там `RadioGroup` или `SegmentedControl`: список ради двух пунктов прячет выбор за лишним кликом.
- **Примечание:** повторный клик по выбранному варианту снимает выбор и отдаёт `null` — иначе список из одного варианта невозможно вернуть в пустое состояние. Там, где пустого значения не существует, ставится `clearable={false}`. Поле над списком — одно на поиск и на свободный ввод, поэтому `allowCustom` включает его сам: `searchable` ради него не нужен.
- **Статус:** готов

### Checkbox
- **Слой:** component
- **Пропы:** `label`, `description`, `indeterminate`, + нативные пропы `<input>`
- **Варианты:** —
- **Состояния:** default, hover, focus-visible, checked, indeterminate, disabled
- **Используется:** фильтры, меню настроек, множественный выбор в `Select`
- **Не использовать для:** выбора одного варианта из нескольких — форма квадрата сообщает «можно выбрать несколько»; там `Radio`. Не использовать как переключатель режима — нужен `Switch`.
- **Статус:** готов

### Radio / RadioGroup
- **Слой:** component
- **Пропы Radio:** `label`, `description`, + нативные пропы `<input>`
- **Пропы RadioGroup:** `name`, `legend`, `direction`, `children`
- **Варианты:** —
- **Состояния:** default, hover, focus-visible, checked, disabled
- **Используется:** выбор режима расчёта, единицы измерения
- **Не использовать для:** одиночной радиокнопки вне группы — её нельзя снять. Всегда внутри `RadioGroup`, иначе выбор не будет взаимоисключающим.
- **Статус:** готов

### Chip
- **Слой:** component
- **Собран из:** Icon
- **Пропы:** `children`, `meta`, `icon`, `onClick`, `action`, `active`, `fullWidth`
- **Варианты:** обычная, активная, с действием
- **Состояния:** default, hover, active, focus-visible
- **Используется:** плашка выбранной дробилки и пробы руды на экранах этапов
- **Не использовать для:** пользовательских меток — там `Tag`, где цвет означает выбор пользователя. Плашка показывает объект и ведёт к действию над ним.
- **Статус:** готов

### Table
- **Слой:** component
- **Собран из:** Icon, Skeleton, EmptyState
- **Пропы:** `columns`, `rows`, `rowKey`, `caption`, `captionHidden`, `sort`, `onSortChange`, `onRowClick`, `loading`, `error`, `empty`, `rowActionKey`
- **Варианты:** с сортировкой и без; с кликабельной строкой и без; с итоговой строкой `TableSummary`; название видимое, убранное с экрана (`captionHidden`) или не заданное вовсе
- **Состояния:** default, hover и focus-visible у строки при `onRowClick`, сортировка по возрастанию и убыванию, loading, empty, error
- **Используется:** список проектов, отчёты, результаты расчёта
- **Не использовать для:** раскладки — таблица означает данные, которые сравнивают по столбцам; для формы есть `Grid`. Не подменять пустую ячейку пробелом: пустое значение показывается прочерком «—», иначе читается как «забыли заполнить». Название опускают только там, где таблицу называет заголовок раздела рядом: иначе в списке заголовков скринридера она останется безымянной. Если название нужно скринридеру, но мешает на экране — `captionHidden`, а не пустой `caption`.
- **Примечание:** кнопку строки при `onRowClick` несёт первая колонка; `rowActionKey` переносит её на названную. Нужно, когда первой стоит колонка с контролом — флажок внутри кнопки недостижим указателем, а именем строки становится подпись флажка.
- **Статус:** готов

### Badge
- **Слой:** component
- **Собран из:** Icon
- **Пропы:** `tone` (neutral|accent|success|warning|danger), `icon` (boolean | иконка, допустимая этой роли), `inText`, `children`
- **Варианты:** neutral, accent, success, warning, danger
- **Состояния:** —
- **Используется:** результат валидации, статус расчёта, состояние проекта
- **Не использовать для:** пользовательских меток — там `Tag`, где цвет означает выбор человека. Не сообщать статус одним цветом: без иконки или текста он не читается при дальтонизме и в печати.
- **Примечание:** какая именно иконка — решает роль, а не место применения: `icon` подставляет иконку тона. Явно указать другую можно только из числа допустимых этой роли (`badgeToneIcons`), `<Badge tone="success" icon="x">` не компилируется. Из двух сигналов, цвета и формы, читатель верит форме — рассогласованная пара сообщает статус наоборот. `inText` включается только внутри строки текста; в раскладке расстояние задаёт `Stack gap`.
- **Статус:** готов

### Switch
- **Слой:** component
- **Пропы:** `label`, `description`, + нативные пропы `<input>`
- **Варианты:** —
- **Состояния:** default, hover, focus-visible, checked, disabled
- **Используется:** настройки, режимы отображения
- **Не использовать для:** значений, которые сохраняются только по кнопке «Сохранить» — переключатель обещает немедленный эффект; там `Checkbox`. Не использовать для выбора из двух вариантов — там `SegmentedControl`.
- **Статус:** готов

### Textarea
- **Слой:** component
- **Пропы:** `rows`, `maxRows`, `invalid`, `fullWidth`, + нативные пропы `<textarea>`
- **Варианты:** —
- **Состояния:** default, hover, focus, focus-visible, invalid, disabled
- **Используется:** примечания к проекту, комментарии
- **Не использовать для:** однострочных значений — высота поля обещает объём. Не растягивать по горизонтали: поле выедет за раскладку формы. Не ставить без `maxRows` в плотной форме: поле растёт за текстом и уносит кнопки за экран.
- **Статус:** готов

### SegmentedControl
- **Слой:** component
- **Собран из:** Icon
- **Пропы:** `options`, `value`, `onChange`, `size`, `legend`, `fullWidth`
- **Варианты:** —
- **Состояния:** default, hover, focus-visible, checked, disabled
- **Используется:** режим расчёта «Инженерный / Упрощённый», переключение вида
- **Не использовать для:** четырёх и более вариантов — сегменты станут уже подписи и начнут обрезаться; там `Select`. Не использовать как фильтр, который можно снять: один сегмент выбран всегда.
- **Статус:** готов

### Stepper
- **Слой:** component
- **Собран из:** Icon
- **Пропы:** `steps`, `current`, `onStepClick`, `direction`
- **Варианты:** row, column
- **Состояния:** пройден, текущий, будущий, disabled; hover и focus-visible при `onStepClick`
- **Используется:** визард «Дробилка → Руда → Продукт»
- **Не использовать для:** навигации по разделам без порядка — степпер обещает последовательность. Не делать шаги кликабельными без обработчика: кликабельность, которая ничего не делает, обманывает.
- **Статус:** готов

### Tooltip
- **Слой:** component
- **Пропы:** `content`, `placement` (top|bottom), `delay`, `children`
- **Варианты:** top, bottom — сторона выбирается по свободному месту, проп задаёт предпочтение
- **Примечание:** размещение на floating-ui, как у `Popover`: сторона по свободному месту, сдвиг у кромки окна (центрирование по триггеру при этом теряется — прочитать подсказку важнее), пузырь в портале. Показан — смонтирован; скрытого пузыря в дереве нет
- **Состояния:** скрыт, показан; появление по наведению и по фокусу, скрытие по Esc
- **Используется:** глоссарий обозначений, расшифровка сокращений
- **Не использовать для:** текста, без которого нельзя работать — подсказка недоступна с сенсорного экрана; важное объясняет `hint` у `Field`. Не класть внутрь интерактивные элементы: до них нельзя дотянуться мышью, не потеряв подсказку.
- **Статус:** готов

### Skeleton
- **Слой:** component
- **Пропы:** `variant` (text|block|control), `lines`, `fullWidth`
- **Варианты:** text, block, control
- **Состояния:** —
- **Используется:** `Table` в состоянии загрузки, области с данными
- **Не использовать для:** областей, которые останутся пустыми — пустота это `EmptyState`, и текст там другой. Не показывать заготовку дольше нескольких секунд: затянувшаяся загрузка — это ошибка, и о ней надо сказать.
- **Статус:** готов

### Link
- **Слой:** component
- **Собран из:** Icon
- **Пропы:** `href`, `external`, `tone` (accent|muted), + нативные пропы `<a>`
- **Варианты:** accent, muted; внутренняя и внешняя
- **Состояния:** default, hover, active, focus-visible
- **Используется:** навигация, ссылки на документы
- **Не использовать для:** действий — если по нажатию что-то выполняется, а не открывается адрес, нужен `Button`. Ссылку копируют и открывают в новой вкладке, с действием так нельзя.
- **Статус:** готов

### AppHeader / HeaderButton / HeaderDivider / HeaderLogo
- **Слой:** component
- **Собран из:** Icon, Text
- **Слоты:** `AppHeader.Left` и `AppHeader.Right` — две части полосы. Обе принимают любые ячейки: разделение про сторону полосы, а не про назначение
- **Пропы HeaderButton:** `icon`, `children`, `active`, `expandable`, `chrome`, + нативные пропы `<button>`
- **Пропы HeaderLogo:** `children` (строка, `svg` или `img`), `label`, `onClick`, `active`, + нативные пропы `<button>`. `label` и `onClick` обязательны
- **Варианты:** две части полосы; ячейка — только иконка (44×44), с подписью, с раскрытием, активная вкладка, кнопки управления окном; знак сервиса — такая же ячейка, ведущая на главную
- **Состояния:** default, hover, focus-visible, active, disabled; `chrome="close"` краснеет при наведении. У `HeaderLogo` те же состояния, что у ячейки, кроме приглушения в покое: бренд не бывает второстепенным элементом полосы
- **Используется:** оболочка приложения
- **Не использовать для:** действий внутри содержимого — там `Button`. У ячейки шапки нет собственной высоты и отступов, она заполняет полосу целиком; попытка выразить обе сущности одним компонентом даёт проп `variant="header"`, отменяющий половину остальных. Не ставить рядом со знаком ячейку `icon="home"` — это одно действие двумя элементами подряд: на главную ведёт сам знак. Не хранить сам знак в системе: бренд приходит снаружи, иначе библиотека не переносится между сервисами.
- **Примечание:** `HeaderSpacer` устарел, замена — `AppHeader.Right`. Экспорт сохранён, чтобы не ломать сборку на месте, но в витрине его больше нет.
- **Статус:** готов

## Правило добавления

Новый компонент не создаётся без явного согласия. Запрос формулируется так:

1. Какую роль он закрывает.
2. Какой существующий ближе всего и чем именно не подходит.
3. Что сломается, если использовать существующий.

После добавления — запись в этот файл вместе с секцией «Не использовать для», иначе компонент считается непостроенным.
