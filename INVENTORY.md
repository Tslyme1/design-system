# INVENTORY — реестр компонентов

Читается перед любой вёрсткой. Прежде чем создавать компонент, проверь, что его здесь нет.

Секция **«Не использовать для»** обязательна у каждой записи. Именно она предотвращает появление пятого варианта карточки.

Статус: `готов` — можно использовать. `нужен` — в аудите найден, ещё не построен.

---

## Примитивы

### Stack
- **Слой:** primitive
- **Пропы:** `direction` (row|column), `gap` (SpaceToken), `align`, `justify`, `wrap`, `grow`, `as`
- **Варианты:** —
- **Состояния:** —
- **Используется:** везде
- **Не использовать для:** сеток из трёх и более колонок — для них нужен `Grid` (пока не построен, спросить). Не использовать вместо `Box`, когда нужен только внутренний отступ.
- **Статус:** готов

### Box
- **Слой:** primitive
- **Пропы:** `padding`, `paddingX`, `paddingY` (SpaceToken), `background` (SurfaceColorToken), `radius`, `border`, `fullWidth`, `as`
- **Варианты:** —
- **Состояния:** —
- **Используется:** везде
- **Не использовать для:** расстояния между соседями — это задача `Stack gap`. Box намеренно не умеет внешние отступы.
- **Статус:** готов

### Text
- **Слой:** primitive
- **Пропы:** `variant` (TextVariantToken), `color` (TextColorToken), `truncate`, `align`, `as`, `htmlFor`, `id`
- **Варианты:** caption, bodySm, body, bodyLg, label, headingSm, headingMd, headingLg
- **Состояния:** —
- **Используется:** везде
- **Не использовать для:** подгонки размера под макет. Роль выбирается по смыслу; если смысл требует другого размера — это вопрос к шкале, а не к месту применения.
- **Статус:** готов

### Surface
- **Слой:** primitive
- **Пропы:** `level` (ElevationToken), `border`, `radius`, `padding`, `background`, `interactive`, `fullWidth`, `as`
- **Варианты:** flat, raised, overlay, modal
- **Состояния:** hover, active, focus-visible — только при `interactive`
- **Используется:** Card, EmptyState, панели
- **Не использовать для:** модалок — у `Modal` своя поверхность с оговорённым исключением из правила «тень или бордер».
- **Статус:** готов

### Field
- **Слой:** primitive
- **Пропы:** `label`, `children` (render-функция), `variant`, `hint`, `error`, `required`, `fullWidth`
- **Варианты:** `stacked` (подпись над контролом, по умолчанию), `floating` (подпись в поле, уходит наверх при вводе)
- **Состояния:** default, focus, filled, error, disabled
- **Используется:** все формы
- **Не использовать для:** полей без подписи. Поле без подписи — это поле без назначения; если подпись мешает макету, это вопрос к макету. Не делать отдельный компонент для плавающей подписи — это вариант, иначе появятся два способа подписать поле и они разойдутся.
- **Примечание:** `floating` держится на `:placeholder-shown`, поэтому контрол обязан прокинуть `placeholder` из render-пропов. Контролы с собственным триггером (`Select`) сообщают заполненность через `data-filled`.
- **Статус:** готов

### Icon
- **Слой:** primitive
- **Пропы:** `name` (IconName), `size` (sm|md|lg), `color` (TextColorToken), `label`
- **Варианты:** 32 иконки Lucide, обводка 1.5
- **Состояния:** наследует `currentColor` от родителя
- **Используется:** Button, Tag, Modal, EmptyState
- **Не использовать для:** иллюстраций и схем. Набор закрыт: добавление иконки требует согласия, как и добавление токена.
- **Статус:** готов

## Компоненты

### Button
- **Слой:** component
- **Собран из:** Icon
- **Пропы:** `variant`, `size`, `iconStart`, `iconEnd`, `fullWidth`, `loading`, + нативные пропы `<button>`
- **Варианты:** primary, secondary, ghost, danger
- **Состояния:** default, hover, active, focus-visible, disabled, loading
- **Используется:** везде
- **Не использовать для:** навигации по ссылке — нужен `Link` (не построен, спросить). Не ставить две `primary` на один экран: если их две, главное действие не выбрано.
- **Статус:** готов

### Modal
- **Слой:** component
- **Собран из:** Text, Icon
- **Пропы:** `open`, `onClose`, `title`, `children`, `footer`, `size` (sm|lg), `dismissible`
- **Слоты:** шапка (заголовок + закрытие) — зашита; содержимое — свободно; футер — `Modal.Footer` с пропом `aside`
- **Состояния:** открыта, закрыта; удержание фокуса, возврат фокуса, блокировка прокрутки страницы, закрытие по Esc и клику по фону
- **Используется:** подтверждения, формы, визарды
- **Не использовать для:** выпадающих меню и поповеров — нужен `Popover` (не построен). Не зашивать внутрь частные решения: всё содержимое приходит снаружи.
- **Статус:** готов

### Input
- **Слой:** component
- **Пропы:** `size`, `invalid`, `fullWidth`, + нативные пропы `<input>`
- **Варианты:** —
- **Состояния:** default, hover, focus, focus-visible, invalid, disabled
- **Используется:** формы, фильтры, поиск
- **Не использовать для:** многострочного ввода — нужен `Textarea` (не построен). Не применять плавающую подпись: подпись ставит `Field`, одинаково для всех полей.
- **Статус:** готов

### Tag
- **Слой:** component
- **Собран из:** Icon
- **Пропы:** `color` (TagColorToken), `onRemove`
- **Варианты:** steel, sage, amber, clay, violet, slate
- **Состояния:** default; hover и focus-visible у кнопки снятия
- **Используется:** метки проектов, фильтры
- **Не использовать для:** статусов системы (успех, ошибка, предупреждение) — там цвет означает роль, а здесь пользовательский выбор. Для статусов нужен `Badge` (не построен).
- **Статус:** готов

### Card
- **Слой:** component
- **Собран из:** Surface, Stack, Text
- **Пропы:** `kicker`, `title`, `actions`, `blueprint`, `onClick`, `children`
- **Варианты:** обычная, `blueprint` (с регистрационными метками по углам)
- **Состояния:** default; hover, active, focus-visible — при наличии `onClick`
- **Используется:** списки проектов, сводки
- **Не использовать для:** кликабельных строк списка — нужен `ListRow` (не построен). Не скруглять и не заливать: карточка — контурный чертёжный объект.
- **Статус:** готов

### EmptyState
- **Слой:** component
- **Собран из:** Stack, Text, Icon
- **Пропы:** `title`, `description`, `icon`, `action`
- **Варианты:** —
- **Состояния:** —
- **Используется:** любые области с данными
- **Не использовать для:** состояния загрузки — нужен `Skeleton` (не построен). Не использовать для ошибок сети: формулировка идёт от состояния данных, а не от сбоя системы.
- **Статус:** готов

### Popover
- **Слой:** component
- **Пропы:** `open`, `onClose`, `trigger`, `children`, `placement`, `width`, `title`, `footer`
- **Варианты:** размещение `bottom-start | bottom-end | top-start | top-end`; ширина `auto | trigger | sm | md`
- **Состояния:** открыт, закрыт; закрытие по Esc и клику снаружи, возврат фокуса на триггер
- **Используется:** панель фильтров, выбор режима, действия над диаграммой, внутренности `Select`
- **Не использовать для:** решений, где ответ обязателен — поповер не блокирует интерфейс и закрывается случайным кликом; для этого есть `Modal`. Не использовать для подсказок по наведению — нужен `Tooltip` (не построен).
- **Статус:** готов

### Drawer
- **Слой:** component
- **Пропы:** `open`, `onClose`, `children`, `footer`, `title`, `size`
- **Варианты:** `wide` (min(920px, 64%)), `narrow` (min(420px, 80%))
- **Состояния:** открыта, закрыта; закрытие по Esc и клику по затемнению
- **Используется:** панель результата расчёта («Смотреть результат»), список пользователей
- **Не использовать для:** содержимого, требующего блокировки всего интерфейса — панель намеренно оставляет шапку доступной; для этого есть `Modal`.
- **Требование:** родитель обязан иметь `position: relative` и `overflow: hidden` — панель позиционируется абсолютно внутри рабочей области.
- **Статус:** готов

### Select
- **Слой:** component
- **Собран из:** Popover, Checkbox, Icon
- **Пропы:** `options`, `value`, `onChange`, `placeholder`, `size`, `multiple`, `searchable`, `allowCustom`, `footer`, `disabled`, `invalid`, `fullWidth`
- **Варианты:** одиночный и множественный выбор; с поиском; со свободным вводом; с группами; с футером
- **Состояния:** default, hover, open, focus-visible, invalid, disabled, пустой результат поиска
- **Используется:** фильтры, формы, выбор заказчика
- **Не использовать для:** выбора из двух-трёх взаимоисключающих вариантов, которые помещаются на экран — там `RadioGroup` или `SegmentedControl` (не построен): список ради двух пунктов прячет выбор за лишним кликом.
- **Статус:** готов

### Checkbox
- **Слой:** component
- **Пропы:** `label`, `description`, `indeterminate`, + нативные пропы `<input>`
- **Варианты:** —
- **Состояния:** default, hover, focus-visible, checked, indeterminate, disabled
- **Используется:** фильтры, меню настроек, множественный выбор в `Select`
- **Не использовать для:** выбора одного варианта из нескольких — форма квадрата сообщает «можно выбрать несколько»; там `Radio`. Не использовать как переключатель режима — нужен `Switch` (не построен).
- **Статус:** готов

### Radio / RadioGroup
- **Слой:** component
- **Пропы Radio:** `label`, `description`, + нативные пропы `<input>`
- **Пропы RadioGroup:** `name`, `legend`, `direction`, `children`
- **Варианты:** —
- **Состояния:** default, hover, focus-visible, checked, disabled
- **Используется:** выбор режима расчёта, единицы измерения
- **Не использовать для:** одиночной радиокнопки вне группы — её нельзя снять. Всегда внутри `RadioGroup`, иначе выбор не будет взаимоисключающим.
- **Статус:** готов

### Chip
- **Слой:** component
- **Собран из:** Icon
- **Пропы:** `children`, `meta`, `icon`, `onClick`, `action`, `active`, `fullWidth`
- **Варианты:** обычная, активная, с действием
- **Состояния:** default, hover, active, focus-visible
- **Используется:** плашка выбранной дробилки и пробы руды на экранах этапов
- **Не использовать для:** пользовательских меток — там `Tag`, где цвет означает выбор пользователя. Плашка показывает объект и ведёт к действию над ним.
- **Статус:** готов

### AppHeader / HeaderButton / HeaderDivider / HeaderSpacer
- **Слой:** component
- **Собран из:** Icon
- **Пропы HeaderButton:** `icon`, `children`, `active`, `expandable`, `chrome`, + нативные пропы `<button>`
- **Варианты:** только иконка (44×44), с подписью, активная вкладка, кнопки управления окном
- **Состояния:** default, hover, focus-visible, active, disabled; `chrome="close"` краснеет при наведении
- **Используется:** оболочка приложения
- **Не использовать для:** действий внутри содержимого — там `Button`. У ячейки шапки нет собственной высоты и отступов, она заполняет полосу целиком; попытка выразить обе сущности одним компонентом даёт проп `variant="header"`, отменяющий половину остальных.
- **Статус:** готов

## Найдены в аудите, ещё не построены

Перед использованием любого из них — остановиться и обсудить API, а не изобретать на месте.

| Компонент | Роль | Где нужен | Приоритет |
|---|---|---|---|
| `Table` | Таблица данных: заголовок, сортировка, наведение на строку, прочерк «—» для пустых значений | Список проектов, отчёты. 56 вхождений «—» с тремя разными размерами | высокий |
| `IconButton` | Кнопка только с иконкой | В аудите три написания одного и того же: `btn btn-icon btn-ghost`, `btn btn-ghost btn-icon`, с примесью `header-cell` | высокий |
| `Stepper` | Шаги визарда: кружок с номером или галкой + соединительная линия | Дробилка → Руда → Продукт | средний |
| `SegmentedControl` | Два-три взаимоисключающих варианта | Режим «Инженерный / Упрощённый» | средний |
| `Badge` | Статус системы: успех, ошибка, предупреждение | Валидация, результаты расчёта. Сейчас роль ошибочно закрывается `Tag` | средний |
| `Tooltip` | Подсказка по наведению | Глоссарий обозначений | средний |
| `Switch` | Переключатель включено/выключено | Настройки. Сейчас роль ошибочно закрывается `Checkbox` | средний |
| `Textarea` | Многострочный ввод | Примечания к проекту | низкий |
| `Grid` | Сетка из трёх и более колонок | Раскладка форм | низкий |
| `Skeleton` | Состояние загрузки | Области с данными. В аудите не найдено ни одного — загрузка не показывается нигде | низкий |
| `Link` | Текстовая ссылка | Навигация | низкий |

## Правило добавления

Новый компонент не создаётся без явного согласия. Запрос формулируется так:

1. Какую роль он закрывает.
2. Какой существующий ближе всего и чем именно не подходит.
3. Что сломается, если использовать существующий.

После добавления — запись в этот файл вместе с секцией «Не использовать для», иначе компонент считается непостроенным.
